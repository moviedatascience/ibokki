# playtests/

Match logs and balance journals. Written by the MCP playtest server
(`save_playtest`), the playtest CLI, and balance sessions by hand.

- `2026-07-27-greedy-triangle-balance.md` — **the balance journal**: every
  triangle measurement, experiment, and verdict since the first strong-bot
  run, appended chronologically. Named for its first entry; spans sessions.
  Start a new journal file when this one gets unwieldy; keep this one in
  place (links point at it).
- `2026-07-29-blindspot-plan.md` — the bot blind-spot ledger + plan of record.
- Dated `*-mN-<School>-vs-<School>.md` — individual piloted match transcripts.
- `archive/` — historical logs from the June–July playtest eras (cvc series,
  early piloted matches). Superseded by the journal's findings; kept for
  provenance.
